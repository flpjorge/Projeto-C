Projeto: Reserva de Laboratórios da UNAERP (Semana Única)

Contexto: A coordenação precisa de um sistema em C para gerenciar reservas de laboratórios (LAB1, LAB2, etc.) ao longo de uma semana letiva. O sistema deve cadastrar salas, registrar/cancelar reservas por dia/horário, e emitir relatórios de ocupação.
